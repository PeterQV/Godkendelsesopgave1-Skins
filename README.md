# Skins

En mobilapp der forbinder kunder med tattoo artists, barbers og frisører. 
Kunder kan gennemse portefølje, priser og services, og sende en forespørgsel med billede direkte i appen uden at skulle browse Instagram eller Google Maps.

## Features
- Liste over artists/salons med navn, type, lokation og pris
- Detaljeret profilside med portefølje og services
- Send forespørgsel med billede og besked

## Teknologi
- React Native (Expo)
- React Navigation (Stack Navigator)

## Kør projektet
npm install
npx expo start
